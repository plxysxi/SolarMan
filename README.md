# ☀️ SolarMan & PEA Executive Suite

ระบบสรุปการผลิตไฟฟ้าโซล่าเซลล์ คำนวณค่าไฟจริง กฟภ. วิเคราะห์ความคุ้มค่าระดับผู้บริหาร (CEO) และระบบบันทึกข้อมูลสาขาพัทยา  
สำหรับโครงการ **LV Pool Villa & Office Cha-am & Pattaya**

---

## 📌 ภาพรวมระบบและหน้าแสดงผล (4 โหมดหลัก)

1. **หน้า 1: สถิติการผลิต & ใช้ไฟ (Solar Generation & Consumption)**
   - สรุปตัวเลขผลิตไฟฟ้ารายเดือน (9 เดือน) และรายวัน
   - สถิติแยกระหว่างการผลิตพลังงานโซล่าเซลล์ (kWh) และการใช้ไฟฟ้าจริง
2. **หน้า 2: ค่าไฟจริง กฟภ. (4 มิเตอร์)**
   - คำนวณตามบิลค่าไฟฟ้าของการไฟฟ้าส่วนภูมิภาค (PEA)
   - แสดงราคาเฉลี่ยต่อหน่วย (฿/kWh) พร้อมคำนวณส่วนต่างที่ประหยัดได้
3. **หน้า 3: สรุปความคุ้มค่ารายหลัง (CEO Executive View)**
   - สรุปสถิติผลตอบแทนและการคืนทุน (Payback / Savings) รายหลัง
   - แสดงยอดเงินประหยัดสะสมรวม (฿78,011.40+)
4. **หน้า 4: ระบบบันทึกข้อมูลสาขาพัทยา (Pattaya Recording)**
   - แบบฟอร์มบันทึกตัวเลขมิเตอร์ประจำวัน/เดือน
   - คู่มือและขั้นตอนปฏิบัติการของทีมงานหน้างาน

## 🔄 การอัปเดตและซิงก์ข้อมูลด้วย GitHub Desktop

1. เปิดโปรแกรม **GitHub Desktop**
2. เมื่อมีการแก้ไขไฟล์หรืออัปเดตข้อมูล ในช่องทางซ้ายล่าง:
   - พิมพ์ข้อความ Commit เช่น `อัปเดตข้อมูลค่าไฟประจำเดือน...`
   - คลิกปุ่ม **Commit to main**
3. คลิกปุ่ม **Push origin** เพื่อนำข้อมูลขึ้น GitHub ปลอดภัย ไม่สูญหายเมื่อย้ายเครื่องอีกต่อไป
